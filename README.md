# SOCOT

Pachete Windows și actualizări SOCOT. Codul sursă nu este public.

Clientul necesită o licență pentru calculatorul autorizat, conexiune la internet și acces autentificat la server. Serverul nu necesită licență. Descărcarea nu acordă o licență de utilizare.

Actualizările sunt verificate prin manifest semnat. Niciun pachet nu include date operaționale, parole sau chei private.
